# Castla Frontend User Guide

Last updated: 2026-06-12

이 문서는 현재 Castla 프론트엔드 런처와 화면 레이아웃 사용법을 실제 동작 기준으로 정리한 안내서입니다.

## 1. 기본 개념

Castla 프론트엔드는 크게 두 영역으로 동작합니다.

- **뷰포트 영역**: 실제 앱 화면이 표시되는 메인 화면
- **런처 드로어**: 앱 실행, App Pair 관리, 즐겨찾기, 자동실행 설정을 담당하는 사이드 패널

앱 실행 방식은 크게 두 가지입니다.

- **짧게 탭**: 앱을 바로 실행
- **길게 누르기 후 드래그**: 앱을 다른 영역으로 배치하거나 바로가기/자동실행에 등록

현재 드래그는 약 **0.45초 길게 누르기** 후 시작됩니다.

## 2. 화면 모드

상단 레이아웃 버튼으로 세 가지 화면 모드를 전환할 수 있습니다.

### Single

- 한 개 앱만 메인 화면에 표시됩니다.
- 보조 앱 없이 한 화면에 집중하고 싶을 때 사용합니다.
- 새 앱을 실행하면 기본적으로 primary 화면에 표시됩니다.

### Split

- 두 개 앱을 좌우로 나눠 동시에 표시합니다.
- **App 1은 왼쪽**, **App 2는 오른쪽**에 배치됩니다.
- 화면 경계선을 드래그해 좌우 비율을 조절할 수 있습니다.

### Popup

- primary 앱은 배경 메인 화면에 유지됩니다.
- secondary 앱은 떠 있는 팝업 창으로 표시됩니다.
- 팝업 창은 이동, 크기 조절, 최소화, 복원이 가능합니다.
- 같은 Popup 버튼을 다시 누르면 숨겨진 팝업을 다시 복원할 수 있습니다.

## 3. 앱 실행

### 단일 앱 실행

1. 런처에서 앱을 찾습니다.
2. 앱을 짧게 탭합니다.
3. 앱이 현재 레이아웃 정책에 맞춰 실행됩니다.

일반적으로:

- Single 모드에서는 primary 단일 실행
- Split/Popup 모드에서는 상황에 따라 현재 세션 상태를 보고 다시 배치

### 특정 창에 드래그해서 실행

앱을 길게 누른 뒤 드래그하면 화면 밖 드롭 타깃이 활성화됩니다.

- **primary 영역에 드롭**: 메인 창에 실행
- **secondary 영역에 드롭**: 보조 창에 실행

secondary로 드롭할 때:

- 현재 primary 앱이 있으면 `split` 또는 `popup` 조합으로 실행됩니다.
- primary 앱이 없으면 secondary 단독 실행으로 들어갈 수 있습니다.

## 4. Split / Popup에서 두 앱 쓰기

두 앱을 동시에 사용하려면 다음 중 하나를 사용합니다.

### 방법 A: App Pair 실행

- 미리 만들어 둔 App Pair를 탭해서 실행

### 방법 B: 실행 중 조합 확장

1. 먼저 primary 앱을 실행합니다.
2. 런처에서 두 번째 앱을 길게 누릅니다.
3. secondary 영역에 드롭합니다.
4. 현재 모드가 Split이면 좌우 분할, Popup이면 팝업 창으로 실행됩니다.

## 5. App Pair 만들기

App Pair는 두 앱을 한 번에 실행하는 저장된 조합입니다.

### 드래그로 App Pair 만들기

1. 첫 번째 앱을 길게 누릅니다.
2. 같은 드로어 안에서 두 번째 앱 위로 드래그합니다.
3. 두 번째 앱 위에서 잠깐 유지하면 merge target이 잡힙니다.
4. 손을 떼면 **App Pair Editor**가 열립니다.
5. 저장하면 새 App Pair가 생성됩니다.

### App Pair Editor에서 조정할 수 있는 것

- **App 1**
  - Split에서는 왼쪽
  - Popup에서는 배경
- **App 2**
  - Split에서는 오른쪽
  - Popup에서는 떠 있는 창

필요하면 editor 안에서 두 앱 순서를 바꿀 수 있습니다.

### App Pair 실행 규칙

App Pair는 현재 화면 모드를 따릅니다.

- 현재 모드가 **Single 또는 Split**이면 Split 형태로 실행
- 현재 모드가 **Popup**이면 Popup 형태로 실행

## 6. App Pair 수정 / 삭제

- 저장된 App Pair를 다시 열어 앱 구성을 수정할 수 있습니다.
- App Pair를 삭제하면 해당 조합은 목록에서 사라집니다.
- 삭제 시 그 App Pair가 즐겨찾기나 자동실행에 묶여 있으면 관련 저장값도 함께 정리됩니다.

## 7. 런처 탭 설명

런처 상단에는 네 개의 탭이 있습니다.

### Auto-run

- 연결 직후 자동으로 실행할 앱 또는 App Pair를 보여줍니다.
- 가장 빠르게 작업 환경을 복원할 때 사용합니다.

### Starred

- 즐겨찾기 앱과 App Pair를 모아둔 탭입니다.
- 자주 쓰는 조합을 빠르게 실행할 수 있습니다.

### Recent

- 최근 실행한 앱 목록입니다.
- 최근 사용 흐름으로 다시 들어갈 때 편합니다.

### Browse

- 전체 앱과 App Pair를 카테고리별로 탐색하는 기본 탭입니다.

## 8. Auto-run에 넣는 법

### 단일 앱

1. 앱을 길게 누릅니다.
2. 상단 `Auto-run` 탭 쪽으로 드래그합니다.
3. `DROP` 표시가 뜨면 놓습니다.

### App Pair

1. App Pair를 길게 누릅니다.
2. `Auto-run` 탭에 드롭합니다.
3. 해당 Pair가 자동실행 조합으로 저장됩니다.

자동실행은 한 세션에서 한 번만 수행되도록 설계되어 있습니다.

## 9. Starred에 넣는 법

1. 앱 또는 App Pair를 길게 누릅니다.
2. 상단 `Starred` 탭 쪽으로 드래그합니다.
3. `DROP` 표시가 뜨면 놓습니다.

다시 같은 항목을 드래그해 즐겨찾기 상태를 변경할 수 있습니다.

## 10. 바로가기에서 제거하는 법

앱 또는 App Pair를 길게 누른 뒤 화면 아래쪽 **Remove** 영역으로 드롭하면 정리할 수 있습니다.

- 일반 앱:
  - 즐겨찾기 제거
  - 자동실행 제거
- App Pair:
  - Pair 자체 삭제 가능

## 11. Split / Popup 사용 팁

### Split 비율 조절

- Split 경계선을 드래그해서 좌우 폭을 조절할 수 있습니다.
- 현재 비율은 브라우저 저장소에 유지됩니다.

### Popup 이동 / 크기 조절

- 팝업 헤더를 잡고 이동할 수 있습니다.
- 가장자리 핸들을 드래그해서 크기 조절이 가능합니다.
- 최소화한 팝업은 다시 복원할 수 있습니다.

### Swap

- 두 앱이 같이 떠 있는 상태에서 Swap을 사용하면 primary/secondary 순서를 교환합니다.
- App Pair 저장 순서도 함께 맞춰집니다.

## 12. 검색과 탐색

- 런처 검색창에서 앱 이름으로 검색할 수 있습니다.
- Browse 탭에서는 카테고리별로 접고 펼칠 수 있습니다.
- 드래그 중 Browse 탭의 다른 카테고리 헤더 위에 잠깐 머물면 자동으로 해당 카테고리가 열립니다.

## 13. 저장 위치와 주의점

다음 정보는 브라우저의 로컬 저장소에 보관됩니다.

- 즐겨찾기
- 최근 실행 목록
- App Pair
- 자동실행 앱
- split 비율
- popup 위치와 크기

따라서:

- 브라우저 데이터가 지워지면 이 설정들도 초기화될 수 있습니다.
- 같은 계정/같은 기기라도 브라우저 저장소가 초기화되면 다시 설정해야 할 수 있습니다.

## 14. 빠른 사용 예시

### 예시 1: 내비 + 유튜브를 Split으로 쓰기

1. 레이아웃을 `Split`으로 전환합니다.
2. 내비 앱을 탭해 실행합니다.
3. 유튜브 앱을 길게 눌러 secondary 영역에 드롭합니다.
4. 필요하면 Split 경계를 조정합니다.

### 예시 2: 지도 + 메신저를 Popup으로 쓰기

1. 레이아웃을 `Popup`으로 전환합니다.
2. 지도 앱을 탭해 실행합니다.
3. 메신저 앱을 길게 눌러 secondary 영역에 드롭합니다.
4. 팝업 창 위치와 크기를 조정합니다.

### 예시 3: 출근용 App Pair 만들기

1. 첫 번째 앱을 길게 누릅니다.
2. 두 번째 앱 위로 드래그해 App Pair를 생성합니다.
3. Editor에서 순서를 확인하고 저장합니다.
4. 새 App Pair를 `Auto-run` 또는 `Starred`에 드롭합니다.
