# Castla Frontend User Guide

Last updated: 2026-06-14

이 문서는 현재 Castla 프론트엔드 런처와 화면 레이아웃 사용법을 실제 동작 기준으로 정리한 안내서입니다.

## 1. 기본 개념

Castla 프론트엔드는 크게 두 영역으로 동작합니다.

- **뷰포트 영역**: 실제 앱 화면이 표시되는 메인 화면
- **런처 드로어**: 앱 실행, App Pair 관리, 즐겨찾기, 자동실행 설정을 담당하는 사이드 패널

앱 실행 방식은 크게 두 가지입니다.

- **짧게 탭**: 앱을 바로 실행
- **길게 누르기 후 드래그**: 앱을 다른 영역으로 배치하거나 바로가기/자동실행에 등록

현재 드래그는 약 **0.45초 길게 누르기** 후 시작됩니다.

## 2. 화면 배치 개념

현재 Castla는 예전처럼 `split`과 `popup`을 완전히 별도 모드로 보기보다, **primary + secondary 배치** 개념으로 동작합니다.

배치 종류는 다음과 같습니다.

- **Single**
  - primary 앱만 전체 화면으로 표시합니다.
- **Left / Right**
  - secondary 앱을 primary의 왼쪽 또는 오른쪽에 도킹합니다.
- **Top / Bottom**
  - secondary 앱을 primary의 위쪽 또는 아래쪽에 도킹합니다.
- **Popup**
  - primary 앱은 배경에 유지하고, secondary 앱을 떠 있는 창으로 표시합니다.

즉 사용자는 "Split을 켠다"보다 **"보조 앱을 어디에 둘지 고른다"**에 가깝게 이해하면 됩니다.

## 3. 앱 실행

### 단일 앱 실행

1. 런처에서 앱을 찾습니다.
2. 앱을 짧게 탭합니다.
3. 앱이 현재 레이아웃 정책에 맞춰 실행됩니다.

일반적으로:

- Single 모드에서는 primary 단일 실행
- 이미 secondary가 있는 상태에서는 현재 배치 구조를 유지하면서 앱이 교체될 수 있음

### 배치 타깃으로 드래그해서 실행

앱을 길게 누른 뒤 드래그하면 화면 위에 배치 타깃 오버레이가 표시됩니다.

드롭 가능한 위치는 다음과 같습니다.

- **left**
- **right**
- **top**
- **bottom**
- **popup**

동작 방식:

- primary 앱이 이미 있으면, 드롭한 위치에 secondary 앱이 실행됩니다.
- secondary가 이미 있으면, 같은 secondary를 다른 배치로 옮기는 방식으로 동작할 수 있습니다.
- popup 타깃에 드롭하면 secondary 앱이 팝업으로 열립니다.

## 4. 두 앱 함께 쓰기

두 앱을 동시에 사용하려면 다음 중 하나를 사용합니다.

### 방법 A: App Pair 실행

- 미리 만들어 둔 App Pair를 탭해서 실행

### 방법 B: 실행 중 조합 확장

1. 먼저 primary 앱을 실행합니다.
2. 런처에서 두 번째 앱을 길게 누릅니다.
3. `left`, `right`, `top`, `bottom`, `popup` 중 원하는 배치 타깃에 드롭합니다.
4. 선택한 위치에 맞춰 secondary 앱이 실행됩니다.

## 5. App Pair 만들기

App Pair는 두 앱과 배치 정보를 한 번에 저장하는 실행 프리셋입니다.

### 드래그로 App Pair 만들기

1. 첫 번째 앱을 길게 누릅니다.
2. 같은 드로어 안에서 두 번째 앱 위로 드래그합니다.
3. 두 번째 앱 위에서 잠깐 유지하면 merge target이 잡힙니다.
4. 손을 떼면 **App Pair Editor**가 열립니다.
5. 저장하면 새 App Pair가 생성됩니다.

### App Pair Editor에서 조정할 수 있는 것

- **App 1**
  - primary 앱
- **App 2**
  - secondary 앱
- **배치**
  - `left`, `right`, `top`, `bottom`, `popup`

필요하면 editor 안에서 두 앱 순서를 바꾸고, secondary 배치도 함께 바꿀 수 있습니다.

### App Pair 실행 규칙

App Pair는 저장된 배치 정보대로 실행됩니다.

- `right`로 저장된 Pair는 right split으로 실행
- `top`으로 저장된 Pair는 top split으로 실행
- `popup`으로 저장된 Pair는 popup으로 실행

## 6. App Pair 수정 / 삭제

- 저장된 App Pair를 다시 열어 앱 구성을 수정할 수 있습니다.
- App Pair를 삭제하면 해당 조합은 목록에서 사라집니다.
- 삭제 시 그 App Pair가 즐겨찾기나 자동실행에 묶여 있으면 관련 저장값도 함께 정리됩니다.

## 7. 런처 탭 설명

런처 상단에는 네 개의 탭이 있습니다.

### Auto-run

- 연결 직후 자동으로 실행할 앱 또는 App Pair를 보여줍니다.
- 가장 빠르게 작업 환경을 복원할 때 사용합니다.

### Starred

- 즐겨찾기 앱과 App Pair를 모아둔 탭입니다.
- 자주 쓰는 조합을 빠르게 실행할 수 있습니다.

### Recent

- 최근 실행한 앱 목록입니다.
- 최근 사용 흐름으로 다시 들어갈 때 편합니다.

### Browse

- 전체 앱과 App Pair를 카테고리별로 탐색하는 기본 탭입니다.

## 8. 멀티윈도우 섹션

사이드 드로어에는 멀티윈도우 전용 섹션이 있습니다.

주요 기능은 다음과 같습니다.

- **배치 변경**
  - 현재 secondary 앱을 어디로 옮길지 선택합니다.
  - 누르면 화면 위에 `left / right / top / bottom / popup` 타깃 오버레이가 다시 표시됩니다.
- **주/보조 전환**
  - primary와 secondary 역할을 서로 바꿉니다.
- **Single**
  - secondary 앱을 닫고 primary만 전체 화면으로 돌립니다.

## 9. Auto-run에 넣는 법

### 단일 앱

1. 앱을 길게 누릅니다.
2. 상단 `Auto-run` 탭 쪽으로 드래그합니다.
3. `DROP` 표시가 뜨면 놓습니다.

### App Pair

1. App Pair를 길게 누릅니다.
2. `Auto-run` 탭에 드롭합니다.
3. 해당 Pair가 자동실행 조합으로 저장됩니다.

자동실행은 한 세션에서 한 번만 수행되도록 설계되어 있습니다.

## 10. Starred에 넣는 법

1. 앱 또는 App Pair를 길게 누릅니다.
2. 상단 `Starred` 탭 쪽으로 드래그합니다.
3. `DROP` 표시가 뜨면 놓습니다.

다시 같은 항목을 드래그해 즐겨찾기 상태를 변경할 수 있습니다.

## 11. 바로가기에서 제거하는 법

앱 또는 App Pair를 길게 누른 뒤 화면 아래쪽 **Remove** 영역으로 드롭하면 정리할 수 있습니다.

- 일반 앱:
  - 즐겨찾기 제거
  - 자동실행 제거
- App Pair:
  - Pair 자체 삭제 가능

## 12. 배치 사용 팁

### Left / Right / Top / Bottom 비율 조절

- 도킹 배치에서는 splitbar 손잡이를 드래그해 비율을 조절할 수 있습니다.
- 좌우 배치와 상하 배치는 비율이 따로 저장될 수 있습니다.
- 손잡이는 경계선 전체가 아니라 작은 thumb 중심으로 잡도록 설계되어 있습니다.

### Popup 이동 / 크기 조절

- 팝업 헤더를 잡고 이동할 수 있습니다.
- 가장자리 핸들을 드래그해서 크기 조절이 가능합니다.
- `-` 버튼은 팝업 뷰만 최소화하고, secondary 세션은 유지합니다.
- 최소화한 팝업은 버블로 다시 복원할 수 있습니다.
- `×` 버튼은 popup secondary를 닫고 Single 상태로 돌아갑니다.

### Swap

- 두 앱이 같이 떠 있는 상태에서 Swap을 사용하면 primary/secondary 순서를 교환합니다.
- App Pair 저장 순서도 함께 맞춰집니다.

### OTT 웹 실행

- 일부 OTT 앱은 직접 미러링보다 브라우저 fallback으로 열릴 수 있습니다.
- 넷플릭스 같은 경우는 모바일 앱 유도 페이지 대신 내장 브라우저의 데스크톱 스타일 페이지로 열리도록 보정되어 있습니다.

## 13. 검색과 탐색

- 런처 검색창에서 앱 이름으로 검색할 수 있습니다.
- Browse 탭에서는 카테고리별로 접고 펼칠 수 있습니다.
- 드래그 중 Browse 탭의 다른 카테고리 헤더 위에 잠깐 머물면 자동으로 해당 카테고리가 열립니다.

## 14. 저장 위치와 주의점

다음 정보는 브라우저의 로컬 저장소에 보관됩니다.

- 즐겨찾기
- 최근 실행 목록
- App Pair
- 자동실행 앱
- 좌우 split 비율
- 상하 split 비율
- popup 위치와 크기

따라서:

- 브라우저 데이터가 지워지면 이 설정들도 초기화될 수 있습니다.
- 같은 계정/같은 기기라도 브라우저 저장소가 초기화되면 다시 설정해야 할 수 있습니다.

## 15. 빠른 사용 예시

### 예시 1: 내비 + 유튜브를 Right 배치로 쓰기

1. 내비 앱을 탭해 실행합니다.
2. 유튜브 앱을 길게 누릅니다.
3. 화면 오버레이의 `right` 타깃에 드롭합니다.
4. 필요하면 splitbar 손잡이로 비율을 조정합니다.

### 예시 2: 지도 + 메신저를 Popup으로 쓰기

1. 지도 앱을 탭해 실행합니다.
2. 메신저 앱을 길게 누릅니다.
3. 화면 오버레이의 `popup` 타깃에 드롭합니다.
4. 팝업 창 위치와 크기를 조정합니다.

### 예시 3: 출근용 App Pair 만들기

1. 첫 번째 앱을 길게 누릅니다.
2. 두 번째 앱 위로 드래그해 App Pair를 생성합니다.
3. Editor에서 순서와 배치를 확인하고 저장합니다.
4. 새 App Pair를 `Auto-run` 또는 `Starred`에 드롭합니다.
