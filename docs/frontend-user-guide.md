# Castla 브라우저 사용 가이드

## 연결

1. 휴대폰에서 Shizuku를 실행하고 Castla 권한을 허용합니다.
2. Castla에서 **미러링 시작**을 누릅니다.
3. 휴대폰과 Tesla를 같은 Wi-Fi 또는 휴대폰 핫스팟에 연결합니다.
4. Castla가 표시하는 주소를 Tesla 브라우저에서 엽니다.

브라우저 상태 표시는 다음 의미입니다.

- **서버 활성**: 제어 소켓이 연결되어 앱을 실행할 수 있음
- **서버 연결 안 됨**: Castla 서버 또는 네트워크를 확인해야 함
- **재연결 중**: 기존 연결이 끊겨 자동으로 다시 연결하는 중

한 번에 하나의 브라우저만 Castla를 제어할 수 있습니다.

## 런처

화면 가장자리의 드로어를 열어 앱을 실행합니다.

- 앱을 탭하면 현재 primary 화면에서 실행합니다.
- 앱을 길게 누르면 드래그할 수 있습니다.
- 검색창은 설치된 앱 이름을 검색합니다.
- 앱 페어는 두 앱과 secondary 배치를 함께 저장합니다.

런처 탭은 다음 용도입니다.

- **Auto-run**: 브라우저 연결 후 자동으로 실행할 앱 또는 앱 페어
- **Starred**: 즐겨찾기
- **Recent**: 최근 실행 앱
- **Alerts**: 브라우저에 표시할 알림 앱
- **Browse**: 전체 앱과 앱 페어

앱이나 앱 페어를 길게 누른 뒤 원하는 탭에 놓아 등록할 수 있습니다. 앱 행의 빠른 동작 버튼으로도 즐겨찾기, 자동 실행 및 알림 허용 여부를 바꿀 수 있습니다.

## 화면 배치

Castla 화면은 primary 하나와 선택적인 secondary 하나로 구성됩니다.

- **Single**: primary만 전체 화면으로 표시
- **Left / Right**: secondary를 왼쪽 또는 오른쪽에 배치
- **Top / Bottom**: secondary를 위쪽 또는 아래쪽에 배치
- **Popup**: secondary를 떠 있는 창으로 표시

두 번째 앱을 길게 누른 뒤 화면의 배치 영역에 놓으면 secondary로 실행됩니다. 실행 중인 secondary는 배치 선택 기능으로 다른 위치로 옮길 수 있습니다.

도킹된 두 화면 사이의 손잡이를 드래그하면 비율이 바뀝니다. Popup은 헤더로 이동하고 가장자리로 크기를 조절할 수 있으며, 투명도 조절·최소화·닫기를 지원합니다.

**Swap**은 primary와 secondary 역할을 교환합니다. **Single**은 secondary를 닫고 primary만 남깁니다.

## 앱 페어

앱 페어를 만들려면 앱을 길게 누른 뒤 다른 앱 위에 놓습니다. 편집 화면에서 다음 값을 확인하고 저장합니다.

- primary 앱
- secondary 앱
- secondary 위치: left, right, top, bottom 또는 popup

저장된 앱 페어를 탭하면 두 앱과 배치가 함께 실행됩니다. 편집 화면에서 구성과 위치를 변경하거나 페어를 삭제할 수 있습니다.

## 오디오

- **기기 오디오 스트리밍 끔**: Android의 기존 출력 경로를 사용합니다.
- **기기 오디오 스트리밍 켬**: 선택된 앱 오디오를 브라우저로 전송합니다.
- **내비게이션 오디오 분리**: 내비게이션 앱을 휴대폰 출력에 남길 수 있습니다.
- **Opus 우선 / PCM 우선**: 네트워크 효율 또는 호환성을 선택합니다.
- **A/V 오프셋**: 음수는 영상을, 양수는 브라우저 오디오를 지연합니다.

브라우저 정책상 오디오는 첫 사용자 입력 뒤에 시작될 수 있습니다.

## 알림

휴대폰에서 Castla의 알림 접근 권한을 허용해야 합니다. 런처의 **Alerts** 탭에 앱을 등록하면 해당 앱의 새 알림을 오버레이로 표시하고 브라우저 세션의 알림 기록에 보관합니다.

민감한 앱이나 표시하지 않을 앱은 Alerts에서 제거하십시오. 알림 기록은 브라우저 메모리에만 유지되며 세션을 초기화하면 비워집니다.

## 문제 해결

### 서버에 연결되지 않음

- 휴대폰과 Tesla가 같은 네트워크인지 확인합니다.
- Castla의 서버 상태와 표시 주소를 확인합니다.
- Shizuku가 실행 중이며 Castla 권한이 허용됐는지 확인합니다.

### 화면이 멈추거나 검게 표시됨

- 잠시 기다려 재연결과 키프레임 복구가 끝나는지 확인합니다.
- 계속되면 Castla에서 서버를 종료한 뒤 다시 시작합니다.
- 다른 브라우저 탭이 Castla 제어권을 가지고 있지 않은지 확인합니다.

### 터치 위치가 맞지 않음

- 레이아웃 변경 또는 크기 조절이 끝난 뒤 다시 입력합니다.
- Tesla 브라우저의 페이지 확대/축소를 기본값으로 되돌립니다.

### 소리가 나지 않음

- 브라우저 화면을 한 번 터치해 오디오 재생을 활성화합니다.
- Castla의 오디오 스트리밍 설정과 대상 앱 분류를 확인합니다.
- Opus에서 문제가 계속되면 PCM 우선을 시험합니다.
