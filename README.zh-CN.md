Castla使用Shizuku在Android手机上创建独立虚拟显示器，并将其传输到特斯拉浏览器。它支持触控、单屏/分屏/弹窗布局、音频串流、通知浮层和可选的热点控制。

## 系统要求

- Android 8.0或更高版本
- 已运行并授权Castla的[Shizuku](https://shizuku.rikka.app/)
- 带内置浏览器的特斯拉
- 手机和车辆连接到同一Wi-Fi或手机热点

## 安装和使用

1. 从[Releases](https://github.com/fbezita/castla/releases/latest)下载并安装APK。
2. 通过无线调试启动Shizuku，并授权Castla。
3. 将手机和特斯拉连接到同一网络。
4. 在Castla中启动镜像服务器。
5. 在特斯拉浏览器中打开Castla显示的地址。

详细设置请参阅[Shizuku设置指南](shizuku-install-guide.md)和[浏览器使用指南](docs/frontend-user-guide.md)。
